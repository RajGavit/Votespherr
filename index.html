Welcome to VoteSphere

VoteSphere is a college project prototype connected to a Node.js API and MySQL database.

01Explore admin modulesManage elections, browse candidates and voters, review results, and resolve complaints.

02Preview student votingUse Student login, then visit Cast vote to review positions and submit selections when an election is active.

03Database-backed modulesElections, positions, candidates, voters, results and vote recording use the local API and MySQL. Complaints are illustrative in this academic prototype.
